# 博士申请管理器

> **原在线版本（尚未更新本次功能）：** https://14677c494413464eb57c5cb4a3092887.sg.agentos-app.run

一个帮你把零散申请信息集中管理的工具。支持 Supabase 邮箱登录、云端数据库、多设备同步，以及申请截止日、推荐信和导师跟进的主动提醒；未配置云服务时继续使用本机模式。

> 仓库已接入云端功能，但需要按[云端配置指南](docs/cloud-setup.md)创建 Supabase 项目、执行建库脚本并配置环境变量后才能启用。上方已有在线站点也需要重新部署才会更新。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **账号与云端同步** | 邮箱注册和登录，六类申请数据按账号保存到 Supabase；支持多设备访问、本机缓存、断网重试、同步状态及冲突保护。 |
| **申请总览** | 集中展示所有申请学校，显示截止日倒计时、资助情况、梯队标签。支持添加、编辑、删除、搁置学校，一键跳转官网。 |
| **材料清单** | 按学校追踪通用申请材料（SOP、CV、Writing Sample、成绩单、推荐信、申请费等），支持进度切换、关联导师、记录发送日期与申请费金额。 |
| **导师沟通** | 记录套磁进度，包括导师姓名、职务、联系时间、邮件内容、沟通结果与对申请的影响评估。 |
| **导师管理** | 记录导师主页链接、研究方向、招收情况、具体要求、近年论文。点击导师名字可查看完整档案。 |
| **面试管理** | 记录面试时间、形式（Zoom/现场/电话）、面试官、面试前后备注与反馈，支持关联导师。 |
| **文书资料库** | 按类型分类存放 SOP、Writing Sample、CV 等文书，支持系统内直接编辑和保存。 |
| **推荐人管理** | 追踪推荐人信息、需提交推荐信数量、已提交数量、提醒时间与当前状态。 |
| **申请梯队** | 按冲刺 / 主申 / 保底梯队分表展示，支持按国家、方向、资助情况筛选。 |
| **备选与搁置** | 把暂不考虑的项目移入此处，后续可随时重新激活回主列表。 |
| **主动提醒** | 顶部铃铛汇总截止日、推荐信和导师跟进提醒，自动弹出页面提示，可选开启桌面浏览器系统通知。 |

## 快速开始

### 1. 在线使用

上方链接仍是原在线版本，云端同步和主动提醒需更新部署后才可在那里使用。体验当前仓库的新功能，请先按下方步骤本地运行。

### 2. 本地运行

```bash
# 进入项目目录
cd phd-tracker

# 安装依赖
npm install

# 如需云端登录，请先完成下方的 Supabase 配置
# 启动开发服务器
npm run dev
```

打开终端输出的地址（通常是 `http://localhost:5173/`），使用期间保持开发服务器运行。

### 3. 启用 Supabase 云端登录

1. 创建 Supabase 项目，在 SQL Editor 中运行一次 [`supabase/migrations/001_tracker.sql`](supabase/migrations/001_tracker.sql)。
2. 将根目录的 [`.env.example`](.env.example) 复制为 `.env.local`，填写 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY`（publishable 或旧版 anon 公钥）。不要填入 service_role 密钥。
3. 配置邮箱登录及验证邮件的跳转地址，详细步骤见[云端配置指南](docs/cloud-setup.md)。
4. 启动或重启开发服务器，在应用中注册、验证邮箱并登录。新账号默认从空数据开始。
5. 通过顶部「导入旧数据」或侧栏「导入备份」迁移已有数据，等待「已与云端同步」后刷新检查。

未配置云服务时，顶部显示「本机模式」，可以继续使用本机数据及页面提醒。

### 4. 检查与构建

```bash
npm test
npm run lint
npm run build
```

`npm test` 使用 Node.js 22.18 或更新版本，覆盖提醒日期边界、每日去重、同步恢复、数据库权限与版本保护。构建结果输出到 `dist`；构建本身不会发布网站。

独立托管方案采用 **EdgeOne + GitHub 自动部署**，详见[部署指南](docs/edgeone-deploy.md)。仓库已包含构建和路由配置；首次仍需在 EdgeOne 关联仓库、填写两项 Supabase 环境变量。连接完成并开启自动部署后，推送到关联的 `main` 分支会触发网站更新。原 WorkBuddy 网站不会自动更新。

## 云端数据与多设备同步

- 学校、材料、导师、文书、推荐人、面试数据按登录账号隔离，保存到 Supabase 数据库。
- 换设备后打开已部署的新版网站、登录同一账号，即可自动读取云端数据。本机的 `localhost` 地址只能用于本机访问。
- 编辑先写入本机缓存，每 3 秒尝试同步；窗口重新获得焦点或网络恢复时也会检查。以顶部「已与云端同步」为云端保存成功标志。
- 有缓存时支持断网继续编辑；未同步内容仍依赖本机缓存。关闭标签页后留下的未同步副本可在同一浏览器重新登录后下载恢复。
- 多设备同时修改时采用整份快照的版本检查，发生冲突会暂停上传。通过「导出本机副本并载入云端」保留副本，再按需补回修改；不会自动合并，即使修改的是不同记录也可能产生冲突。
- 已同步的数据不会因关闭网页或本地开发服务器而消失。GitHub 保存代码，Supabase 保存申请数据，两者独立。
- `.env.local` 已被 Git 忽略；仓库只提交不含实际配置的 `.env.example`。

## 数据备份

本机模式的数据仅保存在当前浏览器中。云端模式下，已同步的数据可在其他设备登录同一账号后读取；未同步的数据仍依赖本机缓存，不要在同步成功前清除浏览器数据。

强烈建议**定期导出备份**：

1. 点击左侧边栏底部的 **「导出备份」** 按钮
2. 系统会下载一个 JSON 文件到本地
3. 需要恢复时，点击 **「导入备份」** 按钮，选择之前下载的 JSON 文件即可

## 主动提醒

- **申请截止日**：进行中的申请在截止前 7 天至截止当天提醒；已提交、录取、拒绝或搁置的申请不提醒，已过截止日不继续弹出。
- **推荐信**：提醒日期到达或已过，且仍有推荐信未提交时提醒；提交数达到总数或状态为已提交时停止。
- **导师跟进**：跟进日期到达或已过时提醒，适用于进行中或已提交的学校；跟进完成后请清空日期，或改为下一次跟进日期。
- 应用打开、数据变化、返回页面时自动检查，同时每分钟检查一次。电脑休眠或后台计时器受限时，返回页面会补查。
- 每项每天最多自动弹出一次页面提示和一次系统通知；更改事项日期后视为新提醒。点击顶部「提醒」可随时查看全部事项，也可选择「今天不再提醒」。
- 在提醒中心点击「开启系统通知」，再允许浏览器通知权限。拒绝授权、不支持通知或通知发送失败时，仍能使用页面提醒。系统勿扰模式可能隐藏系统通知。
- 系统通知面向支持 Notifications API 的桌面浏览器，使用 HTTPS 或 localhost。手机浏览器可使用页面提醒，本版不提供手机后台推送。
- **关闭应用或浏览器后不会推送通知，也不会发送邮件；下次打开会检查当时仍符合条件的事项。** 本版未接入后台定时任务或 Web Push。
- 通知开关、当天提示记录和忽略记录按账号保存在当前浏览器，不上传云端。多设备分别提醒；支持 Web Locks 的浏览器会协调同源多标签页，避免重复弹出。

## 各模块使用指南

### 申请总览

- 点击右上角 **「添加学校」** 填写学校信息
- 卡片上的标签显示：梯队（冲刺/主申/保底）、资助情况、截止日倒计时
- **≤ 7 天** 的截止日会以**红色高亮**提醒
- 点击卡片上的链接图标可跳转学校官网
- 点击暂停图标可将学校移入「备选与搁置」

### 材料清单

- 按学校分组展示所有材料
- 点击状态图标切换进度：**○ 未开始** → **◐ 进行中** → **● 已完成**
- 顶部的进度条显示整体完成比例
- **关联导师**：指定该材料的目标导师（如 SOP 写给哪位导师）
- **发送日期**：材料提交后标记发送时间，显示为绿色标签
- **金额**：申请费时填写费用，显示为金额标签（如 $75）

### 导师沟通

- 记录每位导师的套磁详情
- 标记沟通结果（无回复/积极/中性/消极/面试邀请）
- 评估对申请的影响程度（高/中/低）
- 设置跟进日期，方便追踪后续行动
- 日期到期后在顶部提醒中心提示；跟进完成后清空日期或设置下一次日期
- **点击导师名字可查看完整档案**（研究方向、论文、要求等）

### 导师管理

- 记录导师的**个人主页链接**，方便快速访问
- 填写**研究方向**，了解导师的学术领域
- 标记**招收情况**（正在招生 / 名额已满 / 不确定 / 未知）
- 记录**具体要求**（编程能力、论文要求等）
- 整理**近年论文**，方便面试前复习
- 与「导师沟通」页面**数据互通**，编辑一处全局同步

### 面试管理

- 记录面试时间、形式（Zoom / 现场 / 电话 / 视频）、时长
- **关联已记录的导师**，自动显示导师姓名
- 填写面试官信息
- 面试前准备备注、面试后记录与反馈
- 整体评估（积极 / 中性 / 消极）
- 按时间自动排序，已过期的面试自动标红提醒

### 文书资料库

- 按 SOP / Writing Sample / CV / 其他 分类管理
- 点击文书卡片可查看完整内容
- 支持在系统内直接编辑和保存
- 可关联目标学校和申请方向

### 推荐人管理

- 记录推荐人姓名、邮箱
- 追踪「需提交数」与「已提交数」
- 设置提醒日期，逾期自动标红
- 到期且仍有未提交的推荐信时，自动加入顶部提醒中心
- 状态自动计算：pending → overdue → submitted

### 申请梯队

- 按梯队分表展示，一目了然
- 使用顶部筛选栏按**国家、方向、资助**快速过滤目标学校
- 表格中直接显示截止日倒计时

### 备选与搁置

- 被搁置的学校会显示在此处，卡片呈灰色半透明
- 点击播放图标可随时**重新激活**回主列表
- 也可直接删除不再考虑的项目

## 技术栈

- React 19 + TypeScript + Vite
- Tailwind CSS（暗色主题）
- React Router v7
- Zustand + localStorage 持久化
- Supabase Auth + PostgreSQL 云端持久化，按账号隔离数据
- Lucide React 图标

- 如需重置为初始示例数据，点击左侧边栏底部的「重置数据」按钮
